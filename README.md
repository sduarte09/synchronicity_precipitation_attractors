# synchronicity_precipitation_attractors
Attractor Synchronicity for Climate Prediction in the Bogotá River Basin  Evaluates general synchronization between multi-scale climatic attractors (precipitation &amp; temperature) using Mutual False Nearest Neighbors (MFNN) to improve downscaling of GCM outputs (MPI-ESM-MR) under RCP 4.5 and 8.5 scenarios.
